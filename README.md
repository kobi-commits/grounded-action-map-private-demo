# Grounded Action Map: Gaza V1

## What This Is

A humanitarian foresight, trust evidence, learning, simulation, peacebuilding, and responsible action prototype.

Grounded Action Map helps people move from concern to responsible action by connecting public humanitarian reporting, organization transparency, learning pathways, simulations, peacebuilding lenses, future capacity, and public activation.

## What The Living Map Is

The Living Map is a visual map that connects needs, sources, action, trust evidence, learning, simulation, peacebuilding, future capacity, and public activation.

Core journey:

See -> Understand -> Learn -> Practice -> Act -> Share -> Contribute to the long arc

## What This Is Not

- not a public humanitarian coordination system yet
- not a donation processor
- not an organization ranking tool
- not a prediction engine
- not a certification system
- not a replacement for field actors
- not medical, legal, security, or humanitarian operational advice

## Run Locally

```bash
npm install
npm run dev
```

After the development server starts, open `http://localhost:3000`.

In this Codex preview session the app may also be running on `http://127.0.0.1:3007`.

## Build

```bash
npm run build
```

## Deploy

Push to GitHub and deploy with a Next.js-compatible host such as Vercel.

Before sharing the link, verify:

- build passes locally
- noindex/private demo mode is enabled
- prototype banner is visible
- core routes load
- ReliefWeb feed works or falls back safely
- methodology, review labels, and safety caveats remain visible

## Live Data

ReliefWeb feed is live but unreviewed and does not automatically update sector analysis, action cards, organization profiles, or public recommendations. If the API fails, the app displays fallback sample reports.

## Review Status

All sample content is prototype content and requires human review before public use.

## Safety Constraints

- no unsupported claims
- no organization ranking
- no donation processing
- no beneficiary matching
- no tactical operational data
- no direct contact with minors or vulnerable people
- no public-health advice beyond linking to official guidance
- scenarios are not predictions
- capacity needs require local validation
- regional context is not political forecasting

## Next Steps

Deploy privately, gather expert review, then prepare public beta only after humanitarian, Gaza/oPt contextual, trust/compliance, safeguarding, learning, simulation, foresight, technology/data ethics, and public communication review.
